# PILOTAGEM · site do projeto

Este branch contém só o site publicado no GitHub Pages:

- `index.html`: telas do sistema, roteiro da demonstração e instalação
- `por-dentro/`: arquitetura, banco de dados, controle de concorrência, regra financeira e testes
- `img/`: capturas de tela e marca (as mesmas de `docs/` no branch `main`)

O código do sistema fica no branch [`main`](https://github.com/gusanchez1/pilotagem/tree/main).
